# morenococo.org

Static personal academic site. Plain HTML, CSS and JS. No framework, no build
step: what is in this repository is exactly what is served.

## Deployment

Cloudflare Pages, connected to this repository.

| Setting | Value |
| --- | --- |
| Framework preset | None |
| Build command | *(leave empty)* |
| Build output directory | `/` |
| Production branch | `main` |

Pushing to `main` redeploys. `_redirects` carries 301s from the old WordPress
URLs; `_headers` sets caching and security headers. Both are read by Cloudflare
Pages directly and need no configuration.

## Layout

- `*.html` — the pages
- `assets/css`, `assets/js`, `assets/img` — styles, script, animations and stills
- `assets/data` — downloadable datasets
- `walkthroughs/` — knitted R Markdown code walk-throughs
- `contact/`, `cv/`, `packages/`, `projects/`, `publications/`, `2022/` —
  meta-refresh stubs for old URLs, kept as a fallback for hosts that do not
  read `_redirects`
- `sitemap.xml`, `robots.txt`

Animations are generated by scripts kept outside this repository; the rendered
GIFs are committed here.
